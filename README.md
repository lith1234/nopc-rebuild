# NO PC? NO TRADE. (Fabric, Minecraft 1.21.11)
Needs: JDK 21, Gradle 8.14+ (or the wrapper from the Fabric example mod), Fabric Loader + Fabric API.
Check versions in gradle.properties at https://fabricmc.net/develop, then run `gradle build`.
JAR: build/libs/nopcnotrade-1.0.0.jar -> put in the mods folder (client AND server) next to Fabric API.
Config (created on first launch): config/nopcnotrade.json -> set "targetUsername" and edit any dialogue.
Toaster recipe: 8 iron ingots around 1 redstone.
